# Structured-Light 3D Gallery

Galerie de nuages de points issus d'un prototype de reconstruction 3D par lumière structurée. Les vues sont interactives dans le navigateur.

**[Ouvrir la galerie](https://math680.github.io/structured-light-3d-gallery/)** · [Voir le code de l'imageur](https://github.com/Math680/structured-light-3d-scanner)

| Vue | Ce qu'elle montre |
| --- | --- |
| [Plan](https://math680.github.io/structured-light-3d-gallery/plan.html) | Surface de référence |
| [Pyramide à plat](https://math680.github.io/structured-light-3d-gallery/pyramide-a-plat.html) | Objet géométrique |
| [Bras](https://math680.github.io/structured-light-3d-gallery/bras.html) | Forme organique |
| [Sac](https://math680.github.io/structured-light-3d-gallery/sac-zainab.html) | Objet souple |
| [Mines](https://math680.github.io/structured-light-3d-gallery/mines.html) | Objets fins |
| [Caisse](https://math680.github.io/structured-light-3d-gallery/caisse-bricoleur.html) | Objet aux arêtes marquées |

Le dépôt contient les pages HTML déjà générées et le [script de génération](generer_site_reconstructions.py). Pour comprendre l'acquisition, la calibration et le calcul des points, consultez le [dépôt du scanner 3D](https://github.com/Math680/structured-light-3d-scanner).
