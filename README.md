# Galerie PRONTO · Reconstructions 3D

Galerie de nuages de points issus d'un prototype de reconstruction 3D par lumière structurée. Les vues sont interactives dans le navigateur.

**[Ouvrir la galerie](https://math680.github.io/pronto-reconstructions-3d/)** · [Voir le code de l'imageur](https://github.com/Math680/Pronto-Imageur-3D)

| Vue | Ce qu'elle montre |
| --- | --- |
| [Plan](https://math680.github.io/pronto-reconstructions-3d/plan.html) | Surface de référence |
| [Pyramide à plat](https://math680.github.io/pronto-reconstructions-3d/pyramide-a-plat.html) | Objet géométrique |
| [Bras](https://math680.github.io/pronto-reconstructions-3d/bras.html) | Forme organique |
| [Sac](https://math680.github.io/pronto-reconstructions-3d/sac-zainab.html) | Objet souple |
| [Mines](https://math680.github.io/pronto-reconstructions-3d/mines.html) | Objets fins |
| [Caisse](https://math680.github.io/pronto-reconstructions-3d/caisse-bricoleur.html) | Objet aux arêtes marquées |

Le dépôt contient les pages HTML déjà générées et le [script de génération](generer_site_reconstructions.py). Pour comprendre l'acquisition, la calibration et le calcul des points, consultez le [dépôt principal PRONTO](https://github.com/Math680/Pronto-Imageur-3D).
